## 🌟 Proyectos Destacados

Aquí se encuentran los proyectos clave que demuestran mi capacidad para diseñar, construir y asegurar aplicaciones empresariales de extremo a extremo.

### 1. API de Gestión de Turnos Médicos (Fullstack & DevOps)

Este es mi proyecto principal, donde demuestro la integración de una arquitectura Backend robusta con un despliegue funcional y una interfaz de administración.

* **Descripción:** Sistema integral para la gestión de citas médicas, especialistas y usuarios, implementando un control de acceso basado en roles (RBAC).
* **Habilidades & Tecnologías:**
    * **Backend:** Java 21, Spring Boot 3 y Spring Data JPA.
    * **Seguridad:** Implementación avanzada de **Spring Security con JWT** y autorización granular mediante `@PreAuthorize`.    
    * **Arquitectura de Datos:** Base de datos gestionada en **TiDB Cloud** conectada a un entorno de ejecución en **Render**.
    * **Documentación:** Swagger/OpenAPI 3 para pruebas de endpoints en tiempo real.
    * **Frontend:** Interfaz de administración desarrollada con HTML, CSS, JavaScript y Bootstrap, desplegada en GitHub Pages.

* **🚀 Demo en Vivo (Backend/Swagger):** [Consultorio Turnos API](https://consultorio-turnos.onrender.com/swagger-ui/index.html)
* **💻 Demo en Vivo (Frontend):** [Admin Panel Interface](https://hughob36.github.io/Consultorio_AdminPlan/)
* **📂 Repositorio GitHub:** [Consultorio_Turnos](https://github.com/hughob36/Consultorio_Turnos)

### 2. E-commerce API (Lógica Transaccional & Testing)

Una aplicación Backend que gestiona el ciclo de vida de ventas en línea, con un fuerte enfoque en la integridad de los datos y la validación de procesos de compra.

* **Descripción:** API RESTful para la gestión de un catálogo de productos, carrito de compras y procesamiento de pedidos, asegurando la consistencia del inventario.
* **Habilidades & Tecnologías:**
    * **Backend:** Java 21, Spring Boot 3 y Spring Data JPA.
    * **Calidad de Software (QA):** Implementación de una suite de pruebas completa con **JUnit 5 y Mockito**, garantizando que la lógica de cálculo de totales y manejo de stock sea infalible.
    * **Arquitectura:** Uso de **DTOs** para la transferencia segura de datos y **Manejo Global de Excepciones** para respuestas consistentes al cliente.
    * **Persistencia:** Modelado relacional complejo y consultas optimizadas con MySQL.
* **📂 Repositorio GitHub:** [E-commerce](https://github.com/hughob36/E-commerce)

### 3. Sistema de Gestión de Inventario (Microservicios & Comunicación)

Este proyecto demuestra mi capacidad para diseñar sistemas distribuidos, separando las responsabilidades en servicios independientes y escalables.

* **Descripción:** Aplicación basada en microservicios para el control de stock y almacenes, enfocada en la comunicación eficiente entre componentes.
* **Habilidades & Tecnologías:**
    * **Arquitectura:** Diseño basado en **Microservicios** con **Spring Boot**.
    * **Comunicación:** Implementación de comunicación entre servicios y manejo de consistencia de datos.
    * **Tecnologías:** Java 21, Spring Cloud, Spring Data JPA y MySQL.
    * **Despliegue:** Preparado para contenedorización con **Docker** para asegurar la portabilidad entre entornos.
* **📂 Repositorio GitHub:** [Sistema-de-Gestion-de-Inventario](https://github.com/hughob36/Sistema-de-Gestion-de-Inventario)
