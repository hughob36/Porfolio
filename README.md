### 1. API de Gestión de Turnos Médicos (Microservicio/Proyecto Destacado)

El proyecto más completo que demuestra mi habilidad para construir sistemas robustos y seguros.

* **Descripción:** Una API RESTful completa para la gestión de citas, especialistas, usuarios, roles y permisos (RBAC).
* **Habilidades Demostradas:**
    * **Seguridad:** Implementación de **Spring Security con JWT** y autorización granular (`@PreAuthorize`).
    * **Arquitectura:** Controladores RESTful limpios, separación de la lógica de negocio (Servicios), y uso de **DTOs** para Request y Response.
    * **Manejo de Errores:** Gestión específica de códigos de estado (`201 CREATED`, `409 CONFLICT`, `404 NOT FOUND`).
    * **Documentación:** **Swagger/OpenAPI 3** para documentación interactiva.
